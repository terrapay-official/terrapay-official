TerraPay runs a cross-border payments network that connects banks, mobile wallets and cards. This account publishes the source code of software TerraPay builds on open-source projects, as their licences require.

## Repositories

- [terrapay-sign](https://github.com/terrapay-official/terrapay-sign): TerraPay Sign, our fork of the Documenso document signing platform, licensed AGPL-3.0.

## Security

Report vulnerabilities privately to [security@terrapay.com](mailto:security@terrapay.com), or through a repository's private vulnerability reporting form. Please do not open public issues for security reports.
